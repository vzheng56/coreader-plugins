# Support

For installation and usage questions:

1. Read the [Coreader install guide](https://www.coreader.dev/install).
2. Check the troubleshooting section for your client.
3. Open a GitHub issue with your operating system, Codex or Claude version, plugin version, and any non-sensitive error message or request ID.

Never post access tokens, refresh tokens, authorization codes, cookies, reading content, or Supabase credentials in an issue.
