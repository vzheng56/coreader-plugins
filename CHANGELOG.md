# Changelog

All notable changes to the Coreader plugins are documented here.

## 0.2.0 - 2026-11-16

- Rewrite the skill for the expanded Coreader MCP server: book details and
  table of contents, note browsing, recordings with transcripts, reading
  activity, to-dos, projects and documents, and search that works for Chinese.
- Explain evidence levels so quotes, paraphrases and the reader's own thoughts
  are attributed correctly.
- Reconnect to grant the new permissions (reading activity, projects, audio).

## 0.1.0 - 2026-07-24

- Add public Codex and Claude Code marketplace manifests.
- Connect both clients to the OAuth-backed Coreader MCP service.
- Add shared reading-memory and cited-writing guidance.
- Add bilingual installation and security documentation.
